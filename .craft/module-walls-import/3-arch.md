## Deferred-resolved (Loop 1 handed these to Loop 3)

- **#1 Anchor-space.** Manifest `walls[].{ax,ay,bx,by}` are **SCENE-GRID-normalized** (`ax=u0/cols`, `by=(v0+d)/rows` over the full cols×rows layout grid — see `scene_manifest.py:58-62`). This is NOT the module's `WallDef` space, which is **per-tile IMAGE-S-normalized** (`defToCanvas` maps against ONE tile's `imageRect`, S=max(docW,docH,boundH_px)·imgScale). Feeding manifest anchors straight to `createWallsFromDefs` would cluster all walls onto one tile — WRONG. Bridge: denormalize to canvas (`C=ax*cols*g,…`) then invert through `canvasToAnchor(frameTile,C)`. `defToCanvas∘canvasToAnchor = identity` (wall-coords.ts:74-86), so wall canvas position is **frame-independent**; `frameTile` only supplies linkage (`parentTileId`) + elevation base. cols/rows recovered from tile extents (`max(u)+1,max(v)+1`); manifest carries no grid dims — invariant: enclosed room ⇒ perimeter cells occupied ⇒ `max(u)+1==cols` (holds for l-room, cols=rows=8; verified bx=0.625=5/8). Tiles + walls share the same (cols,rows,g,origin=0) frame ⇒ consistent by construction, independent of the target scene's declared size.
- **#2 imageOffset.** Manifest `imageOffset=[ox/w,oy/h]` = piece-origin as a **UV fraction of the sprite** (`scene_manifest.py:36`; origin = the sprite pixel aligned to the cell ground-corner, `kit_render.py:56`). Module `flags.isoroll.imageOffset` = **grid-unit displacement of the sprite CENTER from the tile center** (`mesh.x = center + off.x*gridSize`, tile-transform.ts:175; stored world-px/gridSize per tiles/CONTEXT.md). Different quantities. **Decision: store the manifest value DIRECT into the flag** (C1: "imageOffset set from manifest"). Justification: pixel-exact sprite registration is the **P2 human-eyeball checkpoint** ("☐ eyeball l-room in Foundry", SCENE-CREATION.md), explicitly NOT an automated criterion (LLM-spatial hard rule: code verifies geometry = counts/round-trips; humans judge visual). No C1–C4 assert sprite position; direct-store is deterministic + unit-testable (flag === manifest value) and cannot fail the count/regression seams. Follow-up (non-blocking, tracked for P2/P6): if eyeball shows misregistration, convert UV-origin→grid-unit center-displacement using piece size (w,h), pxPerVoxel, and the module's `uniform=maxDoc/maxTex` scale — the known lever.
