## Plan Review (adversarial, assume small executors)
- **Wall anchor-space mismatch (the crux):** manifest wall anchors are scene-grid-normalized (`box.u0/cols`), but `createWallsFromDefs(doc,defs)` maps anchors relative to ONE tile's image rect. A medium model would blindly pass manifest walls with a wrong parent tile → placement wrong (but counts still 6). → **fix:** T3 tier raised to **high** and its row explicitly names this as a Loop-3-must-resolve contract (which parent tile / anchor space); Loop 0 tolerance permits placement refinement in P4, so C2 counts are unaffected. Not a criterion-infeasibility.
- **imageOffset semantic drift:** manifest `imageOffset` is image-UV `[u,v]` (matching wall-anchor IMAGE space), but `flags.isoroll.imageOffset` is WORLD-space `{x,y}` (CONTEXT.md). A medium model would guess. → **fix:** T2 row pins the behavior — set the flag verbatim `{x:imageOffset[0], y:imageOffset[1]}`, exact world conversion explicitly deferred to P4 (tolerance). Ambiguity removed.
- **Atomicity (C3) — partial docs:** naive "create tiles, then walls" leaves tiles if walls throw. → **fix:** T4 row mandates full `validateManifest` BEFORE any `createEmbeddedDocuments`; comprehensive upfront validation means the create phase has no expected failure path. Documented in the done-when.
- **Unknown `gridSize`/`u,v→x,y` source:** T2 could be executed with a guessed grid size. → **fix:** T2 row pins `gridSize = scene.grid.size`, `x=u*gridSize`, `y=v*gridSize`, `width=height=gridSize`, passed in by the orchestrator (T4).
- **Allowed facings set for C3:** "unknown facing" is untestable without the allowed set. → **fix:** T1 row names the exact set `{SW,SE,NE,NW}` from exporter `VIEW_TURNS` (verified in `scene_guide_render.py`).
- **`createWallsFromDefs` uses `scene()` (current/active scene), not `sceneId`:** importing into a non-active scene could target the wrong scene for walls. → **noted for Loop 3;** acceptable now because the e2e (C4) imports into the active fx- scene. Flagged in T4/T3 so Loop 3 either activates the target scene or confirms the constraint. Not blocking.
- **Row count / size:** 6 rows ≤ 10 cap; new isolated `src/import/` module keeps each loop file small. No split needed.
